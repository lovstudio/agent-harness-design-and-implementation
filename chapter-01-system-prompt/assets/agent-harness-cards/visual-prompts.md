排成 2:3 卡片。共同限制：无文字、字母、数字、Logo、UI 截图、商标和水印；缩小后
仍要有清楚的主体轮廓。

## Codex

两种互补且平等的半透明建筑形体，在同一张精密工程工作台上共同搭建一个未完成的
结构；一条温暖的绿色引导线连接双方。深炭黑工作室，带纸张、终端网格与少量琥珀
高光；触感纸材、磨砂玻璃和拉丝金属；编辑性 3D 插画，表现主体感、协作和连续关系。

## Claude Code

一件精密抽象工具，只调整橙色边界内的一枚小型机械部件，边界外保持不动。暖白色
技术工作室、测量网格、石墨与拉丝钢；Bauhaus 与工业设计结合的编辑性 3D 插画，
表现最小 scope、克制和验证。

## Pi

大面积哑光石墨空间中，一个开放框架包围着留白的核心，旁边只有少量可替换工具
模块；一枚锋利但非武器的深色几何体穿过中心。冷灰、浅青、烟熏玻璃和机加工铝；
极简编辑性 3D 静物，表现 bootloader、边界和人格留白。

## DSH

深黑紫色建筑场中，一条注册表主干接收多个形状不同的半透明模块；其中一个完整模块
向前滑动并遮蔽其他模块，系统仍保持可组合。轨道、插槽和分支通道清晰可见；烟熏
玻璃、阳极氧化铝和树脂材质；编辑性 3D 插画，表现插件、顺序、作用域和覆盖关系。
